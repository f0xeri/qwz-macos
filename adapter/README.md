# Адаптер qwz/net80211

Здесь наш код, который связывает OpenBSD-драйвер с macOS. В отличие от
`compat/`, это управление конкретным устройством, а не реализация общих
OpenBSD API. Заголовки OpenBSD используются только внутри C-части;
macOS-клиенты работают через `compat/include/qwzmac/attach.h`.

- `device.c`: attach/detach, запуск прошивки, передача кадров и событий
  в kext, shutdown и sleep/wake. Здесь же `config_mountroot`: его поток
  запускает прошивку и интерфейс, а detach ждёт его завершения.
- `control.c`: join/leave, питание радио, запросы сканирования и смены MAC.
  Преобразует запросы клиентов в существующие операции net80211/qwz.
- `status.c`: чтение состояния станции, каналов и результатов сканирования,
  расчёт скорости передачи, снимок для нативного Wi-Fi.
- `internal.h`: приватное состояние устройства, заголовки qwz/net80211 и
  пять функций, нужных нескольким файлам. Не подключать из kext или compat.

Путь управления: `QwzUserClient` либо `QwzAirport → airport_api` →
`control.c` → net80211/qwz. Обратный путь кадров и событий идёт через
`device.c` и `qwzmac_netif_ops`; состояние читается через `status.c`.

Правила блокировок сохранены у функций: spl сериализует доступ к net80211,
`ioctl_rwl` защищает последовательности настройки устройства. Перенос
функции между файлами сам по себе не меняет её контекст выполнения.
